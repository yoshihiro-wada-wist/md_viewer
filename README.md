# Markdown Viewer — Chrome 拡張機能

マークダウンファイルをビジュアルに表示する Chrome 拡張機能です。マークダウン記法で書かれた部分をレンダリングして表示し、**拡大縮小・パン移動・ドラッグ&ドロップ** に対応しています。

## 主な機能

- **ビジュアル表示**: マークダウン記法（見出し・強調・コード・リスト・表・引用・タスクリスト・リンク・画像など）をレンダリング表示
- **Mermaid 図の描画**: ` ```mermaid ` フェンス（フローチャート等）を図として表示
  - 各図は **専用ビューポート** を持ち、図の中を独立して拡大縮小・パン移動できます（図上で `Ctrl`+ホイール／`＋``−``⤢` ボタン／ドラッグ、枠は下端ドラッグで高さ変更可）
- **目次リンク**: `[...](#sec1)` などのページ内アンカーはクリックで該当箇所へ移動
- **目次（インデックスジャンプ）**: 「☰ 目次」ボタン（`Ctrl + I`）で見出し一覧のサイドバーを開き、クリックで該当見出しへジャンプ
  - 見出しレベルに応じた字下げ表示、絞り込み検索、現在位置のハイライト表示に対応
  - `Alt + ↑` / `Alt + ↓` で前後の見出しへ移動
- **拡大縮小**: `Ctrl + マウスホイール`、`＋`/`−` ボタン、`Ctrl + +/-/0` キー、ダブルクリック
- **パン移動**: 表示領域をドラッグして移動（通常ホイールでもスクロール）
- **幅合わせ**: 「幅合わせ」ボタンでキャンバス幅に合わせて表示
- **ドラッグ&ドロップ**: `.md` ファイルをウィンドウに放り込むだけで表示
- 外部ライブラリ非依存・完全自己完結（ネットワーク通信なし）

## インストール手順

1. Chrome で `chrome://extensions` を開く
2. 右上の **「デベロッパーモード」** を ON にする
3. **「パッケージ化されていない拡張機能を読み込む」** をクリック
4. このフォルダ（`md_viewer`）を選択する

## 使い方

### 1. ビューアーを開いてドロップ

- ツールバーの拡張機能アイコンをクリックするとビューアーが開きます
- そこへ `.md` ファイルをドラッグ&ドロップ、または「ファイルを選択」から読み込みます

### 2. `.md` ファイルを直接開く（任意）

ローカルの `.md` ファイルを Chrome で直接開いたときに自動でビジュアル表示するには、
`chrome://extensions` のこの拡張機能の詳細画面で
**「ファイルの URL へのアクセスを許可する」** を ON にしてください。

## 操作方法

| 操作 | 方法 |
|:-----|:-----|
| 拡大 | `Ctrl` + ホイール上 / `＋` ボタン / `Ctrl` `+` / ダブルクリック |
| 縮小 | `Ctrl` + ホイール下 / `−` ボタン / `Ctrl` `-` |
| 等倍に戻す | 「100%」ボタン / `Ctrl` `0` |
| 幅に合わせる | 「幅合わせ」ボタン |
| 文字サイズ変更 | ツールバーの `A−` / `A＋` ボタン（本文の文字だけを拡大縮小） |
| パン移動 | 表示領域をドラッグ / ホイールスクロール |
| 目次の表示/非表示 | 「☰ 目次」ボタン / `Ctrl` `I` |
| 見出しへジャンプ | 目次の項目をクリック / 絞り込み欄で `Enter`（先頭の候補へ） |
| 前後の見出しへ移動 | `Alt` `↑` / `Alt` `↓` |
| ファイルを開く | ドラッグ&ドロップ / 「開く」ボタン |

## トラブルシューティング

- **Mermaid 図が表示されない**:
  - ファイルを更新した後に図が出ない場合は、`chrome://extensions` で本拡張機能の **再読み込み（🔄 更新）** を実行してから、対象ページを再読み込みしてください（拡張機能のファイルを更新した場合は再読み込みが必要です）
  - 図の読み込み・描画に失敗した場合は、画面上部に黄色いバナーで原因（ライブラリ読込失敗・構文エラー等）が表示されます
  - 構文エラーの図はソースコードのまま表示されます（他の正常な図は描画されます）

## ファイル構成

| ファイル | 役割 |
|:---------|:-----|
| `manifest.json` | 拡張機能の定義（Manifest V3） |
| `background.js` | アイコンクリックでビューアーを開く |
| `viewer.html` / `viewer.js` / `viewer.css` | ビューアーページ本体 |
| `markdown.js` | 自己完結型マークダウンパーサー |
| `mermaid.min.js` | Mermaid ダイアグラム描画ライブラリ（ローカル同梱） |
| `content.js` / `content.css` | `.md` を直接開いた際の自動表示 |
| `sample_data/` | 表示確認用のサンプル `.md`（`sample.md`） |
